FRAMIE - CAC FILE CAN CAP NHAT

CACH AP DUNG
1. Sao lưu source FRAMIE hiện tại trước khi ghi đè.
2. Giải nén ZIP này vào thư mục gốc của dự án (thư mục chứa manage.py).
3. Cho phép ghi đè các file trùng tên.
4. Mở terminal tại thư mục dự án và chạy:
   python manage.py migrate
5. Khởi động lại Django server và kiểm tra các luồng Booking.

NOI DUNG
- Chỉ gồm các file source được điều chỉnh/bổ sung, không chứa toàn bộ dự án.
- Có migration chuẩn hóa hai nhãn trạng thái thanh toán cọc/phần còn lại.
- Các URL Use Case hiện có được giữ lại; trang chi tiết Booking dùng chung cho Customer và Photographer.
- Không bao gồm .git, media, static không thay đổi, môi trường ảo hoặc các file không liên quan.

LUU Y KIEM THU
Đã kiểm tra cú pháp Python bằng compileall.
Chưa chạy được Django system check hoặc test suite trong môi trường đóng gói này vì môi trường hiện tại không cài Django.
Sau khi áp dụng, nên chạy:
   python manage.py check
   python manage.py test bookings payments delivery
